# مسار لإدارة المدارس — النسخة الأولية V0.1

نسخة واجهة أولية تعمل مباشرة من المتصفح، هدفها تثبيت بنية النظام قبل ربط Supabase.

## التشغيل
افتح `index.html` في المتصفح أو ارفع المجلد إلى Netlify.

### حسابات العرض
- الإدارة: `admin@masar.local` / `123456`
- المدرس: `teacher@masar.local` / `123456`

## الموجود الآن
- تسجيل دخول تجريبي وحسابان بصلاحيات مختلفة.
- لوحة إدارة ولوحة مدرس.
- إدارة الطلاب والصفوف والشعب.
- عرض المدرسين والمواد.
- إنشاء وعرض جدول الحصص.
- استخراج شعب المدرس تلقائيًا من جدول الحصص.
- شاشات تمهيدية للحضور والدرجات والتقارير.
- مخطط قاعدة بيانات Supabase في `schema.sql` مع أساس سياسات RLS.

## الخطوة التالية
ربط الواجهة بـ Supabase Auth والجداول الفعلية، ثم استبدال بيانات العرض المحلية بالبيانات الحقيقية وتطبيق الصلاحيات على قاعدة البيانات.
